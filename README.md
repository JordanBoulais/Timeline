# TIMELINE


A solo or multiplayer game inspired by a classic board game.
Players take turns placing cards that represent historical events or inventions (with more content to come) in the correct chronological order on the timeline. The first player to empty their hand wins the game.

Playable on both computer and mobile (cross-platform).

    https://timeline.choreoapps.dev/
